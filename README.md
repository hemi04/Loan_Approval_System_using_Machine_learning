# Loan_Approval_System_using_Machine_learning

# 🏦 Loan Approval Prediction System

## 📌 Overview

This project predicts whether a loan application will be **approved or rejected** using Machine Learning techniques.

---

## 🎯 Objective

* Automate loan approval decisions
* Reduce human errors and bias
* Improve efficiency in financial systems

---

## 🛠️ Technologies Used

* Python
* Pandas, NumPy
* Scikit-learn
* Matplotlib, Seaborn

---

## 📊 Dataset Features

* ApplicantIncome
* LoanAmount (in thousands)
* Credit_History
* Education
* Loan_Status (Target: 1 = Approved, 0 = Rejected)

---

## ⚙️ Workflow

```id="t6hy0n"
Data → Preprocessing → Model Training → Model Selection → Prediction
```

This system helps automate loan approval decisions, making them faster and more accurate.
